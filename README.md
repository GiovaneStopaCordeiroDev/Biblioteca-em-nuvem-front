# Biblioteca em Nuvem — Front-end

Front-end da Biblioteca Escolar desenvolvido com HTML, CSS e JavaScript puros.

## Estrutura

- `index.html`: ponto de entrada da aplicação.
- `assets/css`: estilos globais, tokens visuais e estilos das páginas.
- `assets/js`: inicialização, dados, serviços e renderização da interface.
- `assets/fonts`: fontes utilizadas no projeto.
- `assets/icons`: ícones SVG locais.

## Execução local

Sirva a raiz do projeto com um servidor HTTP local. Por exemplo:

```bash
python -m http.server 5500
```

Depois, abra `http://localhost:5500` no navegador.

> O uso de um servidor HTTP é necessário porque o JavaScript utiliza módulos ES.
